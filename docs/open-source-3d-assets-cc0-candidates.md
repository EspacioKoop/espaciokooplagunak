Registro JSON: https://github.com/toxsam/open-source-3D-assets

## Resumen ejecutivo

- 18 colecciones en el registro, 991+ assets listados, CC0 Polygonal Mind en su mayoría
- Candidatos priorizados por área objetivo del módulo Foundry: `escenas y 3D`, `catálogos con procedencia`, `museo-escena`, `andar-nave-app`, `visor-piloto*.mjs`
- Formato de integración preferente: GLB via three.js/GLTFLoader; no se requiere descarga binaria en repo si se referencia por URL permanente
- Riesgo principal: dependencia externa en hosting GitHub raw; mitigación: mirrors en ArDrive/IPFS documentados en el registry

## Criterios de incorporación

1. Mantener assets externos fuera de `foundry-module/` cuando sea posible; cargar por URL con fallback local.
2. Registrar cada asset importado en una sección de créditos aunque sea CC0.
3. Probar carga real en Foundry antes de abrir PR.
4. Preferir colecciones con hosting permanente (GitHub raw, ArDrive, IPFS).

## Siguiente paso recomendado

Seleccionar 1 colección por tema y convertir la lista en PR descargable o en loader dinámico por JSON database.
